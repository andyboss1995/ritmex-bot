# 在新机器上的 setup checklist
1. git clone <repo>; cd ritmex-bot
2. bun install
3. python3 -m pip install futu-api akshare pandas
4. 启动富途 OpenD (默认监听 127.0.0.1:11111)
   - 富途客户端 → 设置 → API 设置 → 启动 OpenD
5. cp .env.hk-momentum.example .env  并填写 (REAL 模式才需要 FUTU_UNLOCK_PWD_MD5)
6. 第一次拉历史数据 (20-30 分钟):
   python3 scripts/futu_pull_universe.py     # 生成 data/hk_universe_kline.json
   python3 scripts/akshare_pull_news.py      # 生成 data/hk_news.json (慢)
7. 每日数据 + 跑策略 (一次性手动验证):
   python3 scripts/futu_pull_snapshot.py
   python3 scripts/akshare_pull_news_realtime.py
   bun run scripts/hk-policy-dry-run.ts      # 只看建议, 不下单
   bun run scripts/hk-policy-live.ts         # 会等 yes 确认
8. 安装 launchd 自动调度 (可选):
   bash launchd/install.sh
9. 验证测试: bun x vitest run src/strategy/hk-momentum-policy
